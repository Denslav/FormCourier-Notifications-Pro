# Security Policy

## Supported version

Security fixes are provided for the latest stable release.

| Version | Supported |
| --- | --- |
| 1.6.x | Yes |
| < 1.6 | No |

## Reporting a vulnerability

Do not disclose security vulnerabilities in public GitHub issues.

Report them privately to:

**support@formcourier.site**

Please include, where possible:
- affected plugin version;
- WordPress and PHP versions;
- reproduction steps;
- expected and actual behaviour;
- relevant logs with secrets removed.

Never include Telegram Bot Tokens, API keys, passwords, private Chat IDs, or other credentials.
